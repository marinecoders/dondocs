# Search captured package contents

Expand **Search captured package**, enter text and run **Search captured text**. Results describe the selected saved revision. A changed library source and other package revisions are outside that search. Each result names the captured member or shared value, shows a matching excerpt and offers its saved context and destination.

Native document and form fields reuse the workspace text inventory. Original PDFs use bounded text-layer inspection; text, CSV and supported Office attachments use their validated retained-text inventory. File reads verify the saved byte length and digest before indexing contents. Missing or inconsistent files produce notices rather than fabricated search matches.

A prepared delivery can supply its own exact captured projection and private resource reader. Its inventory is built after content exclusion. The excluded members, history and metadata cannot contribute snippets. Delivery results retain a deliberate link to the corresponding source package revision.

Search supports up to 200 query characters, two million inspected text characters, 5,000 fields and 100 results. A reached limit is visible; refine the query to inspect a narrower subject. Results are local and temporary. Search does not change documents or confirm extracted information as package facts.

Images without saved recognized text have no text layer to search. Open the source for a visual review or use the package's scanned-evidence workflow when available. Text-layer PDF extraction also cannot read lettering inside scanned images.
