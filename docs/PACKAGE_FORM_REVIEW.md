# Review forms in a package

Start a review of a saved package revision, then open a captured form under **Review captured package members**. **Form field review** lists supported scalar fields and repeated rows. Select a field, enter a reviewer name and comment, then choose **Post form field comment**.

Each comment records the original answer, field kind, form definition and template revision. Repeated rows use their saved identity. Reordering rows does not move a comment to another person. Deleted rows, ambiguous identities and changed definitions remain unavailable when compared with newer content.

Comments are separate from the form answers. **Resolve form comment**, **Undo member comment** and **Redo member comment** change the discussion. They do not change the source document or grant approval. Reviewer names are entered labels.

Captured form feedback survives reload, backup, reviewer-copy export and feedback return. Portable disclosure checks include all labels, captured values and messages. Native correspondence retains its existing text-review controls. Signature and unsupported field types are excluded from field comments.

Comment drafts block member changes and closing through the package controller until posted or cancelled. Closed and superseded rounds are read-only. Saves use the parent package compare-and-swap boundary; cancelled or stale operations preserve the prior saved review.

## Propose and decide corrections

Select a supported field, enter a reviewer name and a typed **Proposed answer**, then choose **Suggest field correction**. Choice and boolean fields use their actual declared options. The captured baseline stays unchanged.

The owning package shows **Decide form corrections**. **Review acceptance** prepares the exact proposed answer; **Review rejection** records a decision while preserving answers. A local acceptance changes only the chosen field and preserves any shared link as an intentional override. The shared scope requires an explicitly entered package value that formats to the proposed answer. Its preview includes every affected linked field; overlapping local edits require a deliberate choice and a fresh preparation.

Review the captured values, affected fields and privacy findings before **Save reviewed form decision**. Preparation never publishes draft files or writes storage. A saved decision appends a package revision and an immutable receipt. The original documents, earlier revisions and exact reviewed baseline remain available.

**Review Undo** prepares a reversal into another revision. It is available while the decision's revision is still current. Newer work prevents a broad Undo; review another correction instead. Cancelled, stale and changed-policy applications preserve saved state and attachments.

Owner decision history is retained in workspace recovery. Reviewer copies and selected-revision editable packages exclude that owning history, consistent with their existing review-authority boundaries. Form proposals remain in exact reviewer copies and feedback returns. Names and decision labels do not authenticate a reviewer or establish approval.
