# Saved administrative requests

Open an existing request from the package library to edit its letter, worksheet or linked fields. If you left intake unfinished, choose **Resume unfinished action**. See [action intake](CONDITIONAL_PACKAGE_INTAKE.md) for saved drafts and transfer.

A saved request contains a plain-paper native letter and a configured **DonDocs request details worksheet**. The worksheet is supporting content, not an official form. The letter's static body refers to the worksheet; it does not duplicate the request narrative. Choose the evidence, routing and signing authority required for the actual request. A printed name adds neither a signature nor an approval.

The requester, recipient, subject, date and SSIC link to the letter's supported headers and the worksheet. The organization and request details link to their worksheet fields. Dates retain their ISO value in package information; letter dates use the supported military-date format. Letter subjects use uppercase. The independent printed signature name remains in the native letter editor.

Use **Package information** to review shared updates, preserve a document field as a local override, reconnect it or inspect older revisions. Open either member in its existing editor for other changes. Editable package transfer includes the exact worksheet definition, template page, shared information and field links.
