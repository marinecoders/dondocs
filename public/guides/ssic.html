Look up a Navy or Marine Corps SSIC

A Standard Subject Identification Code (SSIC) identifies the subject for filing Department of the Navy records. Pick it based on what the correspondence is about.

Search by subject or code

Open the lookup next to the SSIC field in your draft. Search for a subject term such as “correspondence,” or type a known code. Review the description and the surrounding entries before choosing a result.

Check and apply the code

Compare the result with the SSIC manual and any specific filing instructions from your records office. Select the match to fill the field, then verify it in the preview. In NAVMC 10274, the code belongs in block 2, SSIC/File No.

Check the code again when you reuse a draft for a different subject.
